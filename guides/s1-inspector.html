Front panel

Knobs show the stored raw position (0 = fully counter-clockwise, 255 = fully clockwise). Drag up or down, or focus a knob and use ↑ ↓ PgUp PgDn Home End. Hold Shift while dragging for fine steps. Amber tags are SHIFT-pad settings; click one to cycle it. Hover any knob or tag to read the value the S-1's own display shows for it (0–255 for knobs, the 7-segment spelling for switches) — it appears beside the control and in the display box, so a stored pattern can be dialled back in by hand. The display otherwise shows whatever you last touched; click the display to return to the file's tempo.
Status in the tables: verified Roland's control and range, storage confirmed on the hardware or by hardware-tested prior art · reserved stored in every file but no S-1 control exists.

Parameters

Every header key in file order, grouped by section. Raw is what the file stores; Display is the manual's reading of it. CC is the MIDI controller number from Roland's chart.

Sequencer

64 steps, up to four notes each. Steps beyond LAST are kept in the file and shown dimmed. Gate is percent of the step; 100 ties into a repeated note. Probability is stored in tens (10 = 100 %).

Motion (view only)

Eight lanes, each bound to one CC by the MOTION_CC keys, sampled eight times per step. A dot is a recorded value in CC units; a space is no event. Editing motion is out of scope for this page.

OSC Draw and OSC Chop

Draw: 16 wave points from −100 to 100, stored two per word. Chop: 16 on/off segments per wave, stored as a 16-bit mask (green = audible). Chop has no effect while overtone is 0.

Provenance

Format decoded from the 64 factory backup files and confirmed byte-identical on all 64 factory files by tools/s1_prm.py. Panel bindings and ranges from the Owner's Manual v1.02 and MIDI chart 87294690; hardware calibration on 2026-10-25 (live MIDI capture of every knob plus three test backups) confirmed the 0–255 file scale, switch orders, D-Motion axes, delay curve, shuffle, overtone and fine tune: 92 settings verified, 21 reserved keys with no S-1 control. Three independent analyses agreed on every structural point; the consensus is docs/PRM-FORMAT.md. Prior art consulted: denzlobin/S1Utility (GPL-3.0-or-later, not copied), nullent.org draw visualiser, Roland Boutique and AIRA Compact readers.
